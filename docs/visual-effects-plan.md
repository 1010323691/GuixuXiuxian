## 三维斗法台（`static/battle3d.js`，2026-10-21 第二轮）
参考：仙侠御剑与万剑归宗（仙剑/诛仙）、元素色与泛光（原神）、风与云海的动势（对马岛之魂）、动作游戏的顿帧与震屏。
- **场景**：渐变天穹着色器（日月、星河、Boss 雷暴闪电）+ fbm 云海平面 + 实例化公告板云团（沿 x 流动营造御空前行）+ 三层程序远山 + 浮空仙岛亭台 + 掠空风线；境界决定天时：炼气/筑基晨、结丹/元婴昼、化神/炼虚暮、合体以上夜。
- **角色**：几何体拼装、零模型文件。修士（衣袍、发髻、飘带逐帧摆动）脚踏飞剑，剑尾光迹；灵根决定剑光/灵气色（火赤金、木青碧、土琥珀、序章青玉）。本命法宝绕身飞剑（品质决定分身数 3–9），护持法宝为八卦盘。敌形取自立绘同一判定 `enemyLook`：兽/猿/狐（多尾）/蛟（S 形盘身）/傀（岩块+核）/影/灵/魔修；首领（guard/world_boss/elite 或名称）放大 1.55 倍、背后血色法阵光环、天象转雷暴。敌方护盾为六角菲涅尔罩，随剩余护盾出现裂纹。
- **招式映射**：本方普攻按功法——赤霄功火凤火球、玄岳经金色掌印天降、归元诀剑气月牙；运功强攻=身后法阵蓄力+放大+推镜；焚火符=符箓飞掷点燃。本命法宝=万剑归宗（剑影扇形列阵后依次俯冲）。同行=青色灵弹。敌方按外形：扑击爪痕/投石/毒息/暗影触须/血色剑气，重击加红闪。回护=六角罩涟漪+八卦法阵；回元丹=青碧螺旋；护身符=符箓化金色符文环绕；镇魂符=八卦封印+金链锁敌并定身；防御=金钟罩落下+灵息回流；毒=绿瘴；汲灵=蓝色灵流被吸走。胜：敌身化灰烬消散+光柱+环绕运镜；败：灯火渐暗、御剑失衡下坠、画面去饱和。
- **导演与时钟**：入场自云层高处俯冲（≈1.8s）；闲时缓慢环绕与呼吸；每招 蓄力特写→跟随→命中，命中强度=伤害/对应气血上限×3，驱动顿帧（时钟×0.12）、trauma² 震屏、色散与闪色。统一模拟时钟：倍速直接乘；拖动时间轴/跳到结果时 `clear()` 移除全部临时物体并 `setFrame` 直接摆出该拍状态。三维开启时每拍 1.75s（首拍 2.3s 等入场镜头），关闭时仍为 1.3s。
- **竖屏**：宽高比<1 时双方改为一前一后斜对站位，镜头后撤上限 26，保证同框且够大。
- **后期**：RenderPass → UnrealBloom（阈值 1.0，只让>1 的法光泛光）→ 自写暗角/色散/去饱和/闪色 → OutputPass（Neutral 色调映射）。后期扩展来自 three r170 官方 `examples/jsm`，同源内置于 `static/vendor/addons/`，导入路径改为 `/vendor/three.module.min.js`（CSP 禁内联 importmap）。（历史：该斗法台与 addons 已于 v2 阶段二退役，见 D019。）
- **性能**：质量三档（bloom 开关、像素比 0.85/1/1.5、云团 26/44/70、粒子比例），按核数选初始档，90 帧均值>30ms 降档；不可见即停帧；`dispose()` 遍历场景释放全部几何/材质/贴图并释放 composer 与 bloom 目标。
- **信息层**：飘字改为 DOM（`#replay-floaters`，按 `project()` 投影定位），气血/灵力为浮于舞台的 HUD，战果铭牌落在舞台底部；三维丢失（`onLost`）立即回到 SVG。

## 统一管理器（`static/fx3d.js`）
- **单上下文**：`liveRenderers` 记录存活渲染器；战报 `create()` 先 `suspendStage()` 销毁舞台，合上 `dispose()` 后 `resumeStage()` 重建。
- **舞台**：`mountStage({host,tier,color,page,estate})`，宿主/参数变化走 `update`；`app.js` 的 `stage3d` 按需 `import("/fx3d.js")`，失败/`reduced-motion`/无 WebGL 保留 Canvas2D（`body.stage3d-on` 时 2D 画布隐藏）。
- **降级与性能**：≈30fps 上限；宿主不可见/页面隐藏即停帧；DPR≤1.5；按 `hardwareConcurrency` 选初始质量档，连续 90 帧均值>45ms 自动降一档；`stats()` 暴露 fps/帧耗时/质量/几何与纹理数/绘制调用。
- **验证**：`tests.browser_fx3d`（SwiftShader）：单渲染器、灯笼随洞府等级、战报开合30次几何3/纹理2不增长、四种敌形×四种天时完整播放与跳到结果、375×812 无横向溢出、无 WebGL 降级到 SVG；截图在 `artifacts/fx3d-qa/`（不入库）。

## 未覆盖
真实 GPU/低端 GPU 帧率、小时级内存曲线**未测**。SwiftShader 软件渲染下舞台约 13–22fps、斗法台约 8fps，仅说明降级链路有效；本机内置浏览器（硬件 GPU）开发时观察到斗法台约 84fps，非受控测量。真实凡界战斗（服务端生成的战报）+ WebGL 下的斗法台未用自动化套件单独覆盖（合成战报已覆盖全部事件类型）。

## 云海御空 v2 · 阶段一实验场（`src/battle/` → `static/arena3d.js`，2026-10-21）
- 打开方式：启动服务后访问 `/battle-lab.html`（参数：`t=秒` 快进到指定时刻，`hold` 停住，`clean` 隐藏信息条，`q=0|1|2` 画质档，`reduced` 减弱动效）。游戏内不链接。
- 模块：`env.ts` 环境；`actors.ts` 主角（御剑、长发/飘带/披帛/袖尾布料、动作模板权重混合）与魔物（盘角、獠牙、魔纹自发光、膜翼、尾、噪声溶解）；`fx.ts` 特效（three.quarks 粒子池 + 自定义拖尾/法阵/光束/八卦护罩/魔爪/天剑）；`camera.ts` 导演镜头（过肩、侧拍、施法、魔物特写、冲击、仰拍、环绕大全景，缓动切换/硬切、创伤式震屏、FOV 冲击）；`post.ts` 后期（HDR 泛光、AgX 色调映射、调色、暗角、闪白、色差）。
- 剧本（18 秒循环）：御剑入场与魔吼 → 剑阵十二剑弧线俯冲 → 五张符箓扇形连爆 → 法阵展开蓄力后光束 → 魔物怒吼蓄力扑击、八卦镜涟漪格挡与震退 → 天剑自上贯下、魔物溶解。
- 主角（D017）：`src/battle/art.ts` 的 2.5D 立绘主角与设定图道具（飞剑/符箓/法阵/玉佩），素材在 `static/art/hero/`（来源见同目录 `SOURCE.md`）；`?hero=toon` 切回程序化主角对照。
- 对手（D018）：紫晶翼狮王立绘（`static/art/lion/`），紫晶色系特效与「灵气凝聚」阵印；`?foe=demon` 切回旧程序化魔物对照。
- 已知问题（待验收意见）：魔物溶解末段呈暗色剪影；竖屏侧拍会裁掉部分魔物；真实 GPU 帧率与长时内存未测（浏览器面板/无头环境帧率不代表真机）。

- 命中时刻与飘字一致（见 D019 表）；只有第一柄剑/第一张符算「这一击」并给出完整冲击，其余只溅火花，避免连击白屏。

- 群战（阶段三，D021）：战报 `enemy.units` 的每只小怪是一只小号紫晶狮，按槽位排在首领两侧与前方；单体打小怪的飞剑/符箓改瞄该小怪，群攻事件（`aoe`）每只小怪一柄剑/一张符逐只扫过（错峰 90ms），小怪扑击（`unit` 为出手者）小幅冲撞并留爪痕；小怪在该拍最后一次命中后燃烧倒下，首领败亡时残余小怪飞散。回放按本拍事件错峰总长顺延拍长，HUD 敌方气血条下显示小怪气血格。

## 云海御空 v2 · 阶段四：自由飞行、避障与性能（`src/battle/steer.ts`，D022）
- 转向群 `Flock`：固定 30Hz tick（每帧最多追 12 tick，长停顿丢弃积压），渲染在最近两 tick 间插值。每个单位：arrive 到「锚点 + 飞行程序绕飞点」，与其他单位分离（半径和 + 0.6），前方 0.9 秒速度胶囊探针碰到石柱（柱半径 + 单位半径 + 1.5）即侧推绕开，最后硬推出确保从不进入柱体。
- 飞行程序（`PROGRAMS`）：兽绕圈逡巡、猿上下蹿跃、狐忽左忽右急掠、蛟蛇形游走、傀沉稳缓移、影/灵飘忽起伏、人游斗绕步、主角御剑悬停；每个单位按种子取相位、速度 ×0.8–1.25、半径 ×0.8–1.3、轨道倾角，避免整齐划一。
- 锚点：主角在本方位，首领在敌方位（半径随体型），小怪锚在首领当前位置 + 槽位偏移，因此整群随首领游动；冲撞是叠加在 AI 位置上的脚本位移；入场与倒下时该单位 AI 暂停；溃散把小怪锚点改到远处并提速，由 AI 飞离。拖动/跳过时 `settle()` 直接落到锚点。
- 石柱：近场三根（`ARENA_PILLARS`）既是景物也是障碍；`stats()` 给出 `agents/aiHz/avoids/clearance`（全程最小「到柱轴距离 − 柱半径 − 单位半径」）。
- 性能阶梯：连续 90 帧均值 >34ms 降一档：像素比 0.75 → 关闭远景细节（云团、飞鸟、瀑布）→ 像素比 0.6；`stats().level` 为当前档。小怪不带点光源。
- 验证：`tests.browser_fx3d_real` 的 12 单位回放（首领 + 10 小怪 + 主角，含群攻、逐只倒下与溃散）。
