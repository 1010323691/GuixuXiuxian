# 界面与交互契约

状态：已按 API 契约实现原生 HTML/CSS/JavaScript 前端；视觉岗位维护 `static/` 文件，不在前端复制游戏规则。独立验收结果由 QA 维护。多用户在线化（登录、账号菜单、同步状态）的界面要求见下文“账号与同步”，其实现与浏览器验证以 QA 记录为准，未运行的不视为通过。

## 页面结构
游戏采用深墨青背景、古纸文字与少量旧金强调，系统中文衬线标题及无衬线正文，无外部字体和图片请求（正式界面视觉语言已由 V2–V4 迭代取代，见 `docs/iterations/V4_DESIGN_SYSTEM.md`）。采用章节式布局、紧凑账目和连续日志，不堆叠数值卡片。

1. 页头：游戏名、简短修行定位、进度同步状态；账号按钮（显示用户名，菜单含修改密码、退出登录）与新局为次要操作。
2. 顶部摘要：姓名、境界、当前目标及关键状态进度；资源以带名称的数值账目呈现。
3. 主栏：当前场景、可进入区域、行动列表；行动旁明示收益、消耗和前置条件。战斗时原位替换为敌人状态、下一回合意图与战斗指令，不要求在多个页面来回切换。
4. 次栏：当前修行目标说明、人物细节和近期经历；日志有时间/回合或序号、结果与变化，保留历史查看入口。
5. 结局：明确通关文本与后续可用操作，不以达到隐藏状态代替可见结束反馈。

## 进入与行动
未登录时先显示登录/注册面板（见下文），登录后无当前游戏则显示简洁新角色表单，仅姓名，默认“归墟客”；不加入出身、职业或禀赋选择。首次创建没有旧进度无需破坏性确认。

当前状态、动作、成本、可用条件、战斗意图和结果均来自后端。突破为确定性动作，不弹确认，明示满足条件及将发生的变化。禁用动作仍显示原因；资源不足不能只靠灰色提示。

非战斗行动分为修行、游历、山海、行囊四组，用普通按钮的 aria-pressed 表达选中组，当前页面保留选择；默认显示修行。分组只决定展示，不决定可执行性。每行呈现行动名、成本/收益和禁用原因，完整 detail 保留于 title，不重复长段规则。战斗只显示后端返回的战斗动作，不显示分组按钮。

请求进行中禁用状态写入按钮并显示“进行中…”，防止重复点击。成功后使用完整权威快照刷新状态，展示本次事件与变化。前端不得先行增加资源或宣称进度已同步。

## 账号与同步
- 登录/注册面板：用户名、密码两个字段，登录与注册两个页签；字段错误显示在对应字段旁（来自响应的 `error.field`），服务错误显示在面板内；提交中禁用按钮，防止重复提交。限流时显示“尝试次数过多，请 N 分钟后再试”。
- 启动时先请求 `GET /api/session`：未登录显示登录面板，已登录读取进度；等待期间显示“正在同步你的修行进度。”任何请求收到 401 都回到登录面板并保留页面状态，登录后继续。
- 账号菜单：显示用户名，含“修改密码”（旧密码+新密码）与“退出登录”。退出后清空页面内的进度显示。
- 同步状态指示（页头）：进度同步中…、进度已同步（带时间）、同步失败正在重试、网络中断正在重连（动作按钮暂不可用）、进度保存失败请稍后重试且当前操作未生效（提供“重试原操作”）、请先登录。**只有服务端提交成功的响应才能显示“进度已同步”**；失败态绝不显示已同步。
- 没有手动保存或读取进度的按钮；新局是唯一会替换当前角色的入口，使用确认。
- 一屏不滚动（V3/V4 约束）保持，登录面板与账号菜单需适配既有 10 个视口。

## 确认
只有覆盖当前游戏的新局使用确认。确认内容指出“当前角色及其进度将被新的角色替代，此操作无法撤销”，提供清晰取消/继续按钮；取消不发写请求，确认区域可键盘操作，关闭后焦点返回触发按钮。

## 错误与一致性
写请求使用 request_id 与 expected_revision；完整待确认载荷持久化至当前标签 sessionStorage 并记录所属账号，刷新可恢复且标签间隔离；登录账号与记录不一致时丢弃。关闭标签后不承诺恢复原请求 ID，重新打开由 GET 获取最新状态。同次请求重试保留 ID 和原载荷，不自动产生新行动；服务端失败（503）或超时时自动用同一 ID 退避重试有限次，仍失败则停在失败态并提供手动重试。收到版本冲突提示“进度已在其他页面更新，已为你刷新到最新”，并自动重新获取状态，由玩家再决定。

网络中断不把结果直接写成失败或成功；显示“网络中断，正在重连…”与恢复入口，不做离线队列。若契约支持幂等重试，允许用户重试原请求；禁止自动重放为新请求。规则错误保留可读原因，存储错误不能显示“已同步”。加载失败可重试，保留已有可读内容和错误反馈。

## 响应式与可访问性
桌面约 1180px 内容区，主次栏约 2:1；760px 以下单栏，按目标、关键状态、行动、详细信息和日志排序。按钮触达高度至少 44px，无依赖悬停的必要信息，中文可自然换行，320px 宽无横向溢出。

保留语义标题、表单标签、键盘焦点和按钮文本；用数值和文字表达状态，颜色只作辅助。结果通知使用适度 aria-live，非紧急日志不持续抢读。尊重减少动态效果设置，装饰由 CSS 渐变、细线和低对比山形构成，不覆盖正文。

## 验收
实际浏览器验证登录/注册/退出/改密、新建、行动、成长、战斗、突破、结局、刷新续玩和新局确认；覆盖加载、禁用、处理中、规则拒绝、网络失败、保存失败注入、版本冲突与 401 过期。桌面/窄屏、键盘、焦点、日志及中文溢出由 QA 独立验证。本文是实施约束，尚不代表页面或测试已完成。

## 历史前端自测记录（升级前）
升级前的版本曾在独立临时数据与 8101 端口服务上，使用系统 Chromium 和 Playwright 验证：空白姓名默认、修炼、刷新续玩、四分组切换、320px 无横向溢出，以及服务端提交后丢失响应、刷新恢复同 ID 待确认操作、幂等重试和两页版本冲突刷新；当时还包含已退役的手动存取按钮，相应步骤已不再适用。上述流程未见 JS 异常或意外控制台错误。待确认操作只保证当前标签刷新恢复，不承诺关页后恢复原请求 ID。多用户化之后的浏览器结果以 QA 最新记录为准，本机未装 Playwright 时须如实记“未运行”。
