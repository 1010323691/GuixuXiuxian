# 首版交付 v0.1.0

日期：2026-10-20（Asia/Tokyo）。名称：归墟修行手札。范围：本地单人中文文字修仙短篇，从炼气一层至筑基、平息归墟之影，有明确结局并可继续日常修行。

## 运行与内容
Python 3.11+，本环境实测3.12.14；运行无第三方依赖。解压源码包后进入项目根目录，执行 `python server.py --host 127.0.0.1 --port 8000 --data-dir ./data`，在本机浏览器打开对应8000端口页面。完整玩法、备份和恢复说明见根README.md。

包含三处区域、四类敌人、修炼突破、功法两级升级、采药炼丹、可选交易、确定性意图战斗、败退免费恢复、自动保存与单手动检查点。没有装饰性假按钮或在线服务依赖。装备、随机奇遇、宗门经营、多角色、更多境界留作后续扩展，不显示未实现入口。
