# 体验审查（2026-10-21）

## 1. 技术现状（已读代码确认）
- 后端：标准库 Python，`server.py` 单进程 HTTP + SQLite（`data/game.db`，WAL），多账号以会话 Cookie 隔离；规则在 `game/`（rules 序章、world 凡界、growth/cadence/journey/loot 等）。
- 前端：无框架、无构建，`static/index.html` + `app.js`(约2460行) + `battle_replay.js` + `styles.css`(token 两层设计系统「青绿金碧」，见 `docs/iterations/V4_DESIGN_SYSTEM.md`)。状态由服务端权威，前端按 `/api/state` 渲染；写操作带 `request_id`/`expected_revision`。
- 动画：CSS + Canvas2D（舞台灵气粒子、获得飞入、点击涟漪）+ SVG 战报回放。本轮前**没有 Three.js/WebGL**。
- 测试：`python -m tests.parallel` 全量白盒；Playwright 浏览器套件可选。
- 启动：`python server.py --port N --data-dir DIR` 或 `启动游戏.bat`。

## 2. 系统清单
入口(登录/注册/改密/创建角色) · 序章(修炼/探索/地区/首领/买卖) · 潜修(在线离线同速成长) · 凡界工作台(世界/人物/宗门/社交/四艺/探索/洞府/市场/任务/成就/竞技等卷目，右侧任务/回执/进度) · R3/R4 长线(日常周常、七段故事、三精英、副本) · 自动斗法与战报回放 · 账号与同步状态。
