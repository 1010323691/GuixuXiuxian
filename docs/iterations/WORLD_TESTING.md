## 复现
在仓库根目录运行：

```sh
python -m unittest discover -s tests -v
python -m tests.browser_smoke
python -m tests.browser_world
```

标准库测试无需安装包。浏览器测试需要 Python Playwright 与 `/usr/bin/chromium`；游戏运行不依赖测试包。HTTP测试及浏览器均使用独立临时数据目录、随机回环端口和子进程，结束后关闭并清理，不触碰玩家默认data。测试失败保留退出码，零测试或跳过不能视为通过。

## 真实页面覆盖
浏览器从创建姓名、53动作序章到完整凡界结束，使用可见按钮与表单；分页通过公开“展开全部”按钮寻找目标，禁止强制点击隐藏DOM或直接API写入替代交互。11页逐一只读切换，断言没有revision/tick变化；每页实际系统操作由主链与补充洞府、成就称号、三域冠军闭环覆盖。真实提交text/number/select字段，含非默认数量买卖；确认先取消验证无写入，再确认执行；数字0违反范围不得写库。

完整world手动save/load、取消焦点、刷新续玩另有验证，状态深比较而不是只看保存提示。所有11页320px检查无横向溢出。公开动作参数拒绝、禁用原因非空与各系统负面分支由HTTP/规则覆盖；不把截图存在当成所有行为通过。

## 限制
只验证单人本地NPC模拟；没有真人PVP、真实跨服务器或外部账号/付费AI依赖，也不宣称已实现。仙界只留接口，本版没有可游玩仙界。未测实体手机、跨浏览器、完整读屏器和长期极端压力；320px为Chromium视口模拟。自动化耗时不代表真人阅读游玩时长。手动slot是同一世界快照，不是数据库灾备。

后续变更重跑受影响测试，未执行、失败或跳过单独报告；禁止删除有效断言或降低难度隐藏失败。最终版本验收与发布由项目经理负责。
