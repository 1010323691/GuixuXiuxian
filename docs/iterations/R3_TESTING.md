## v1.1交付运行说明（待最终产物解压核验）

游戏只需Python3.11+，不需pip依赖、外部账号或联网服务。在源码目录执行：

```sh
python3 server.py --host 127.0.0.1 --port 8000 --data-dir ./data
```

浏览器打开http://127.0.0.1:8000。新角色默认长线，可在新局表单选自由行动；已有无r3的角色仍是自由行动，不自动转换。长线仍先玩序章，入世才开始现实时间持续修炼；每次成功行动自动保存，退出页面无需手领离线修为。长线手动检查点只恢复安全位置，保留剧情、战斗、资产、经济时间、境界花费与资格；进行中战斗/探索不换地。自由行动仍可完整回档。创建新角色会清当前角色和手动检查点，不能当作旧档转换操作。

升级前先停服，再复制整个data目录作独立备份。schema2直接兼容；schema1须显式执行上述启动命令加`--migrate-save`，服务会先备份再迁移为schema2自由行动档。坏档或未知版本须保留原件恢复备份，禁止删库“修复”。不要同时对同一data目录运行多服务。

独立复验命令：`python3 -m unittest discover -s tests -v`；可选浏览器测试另安装Playwright并提供/usr/bin/chromium，再运行`python3 -m tests.browser_smoke`、`python3 -m tests.browser_world`、`python3 -m tests.browser_r3`。测试自建临时数据库，不使用真实data。`python3 -m tests.r3_projection_check`单独生成新16动作入口证据，不计为unittest用例。

R3的四十多日结果采用注入服务端UTC的合法动作模拟，不能称为已经进行四十天真人测试；日常/周常、掉落与世界Boss均本地NPC单机模拟，不是真人联机或全服排行榜。仙界仍未开放。
