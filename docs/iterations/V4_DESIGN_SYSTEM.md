# V4 设计系统 ·「青绿金碧」

适用范围：正式游戏前端 `static/`（index.html / styles.css / app.js / battle_replay.js 的样式部分）。后端、接口、存档、`prototypes/` 不在范围。
继承的用户裁决（仍然有效）：只做亮色（V2）；去网页化、用游戏界面语言（V2）；任何界面都在一屏内、不出现滚动条，超出部分分页（V3）。
本轮用户要求（2026-10-20）：统一配色、字体、间距、图标和组件风格，建立一致的视觉层级与规范；加入过渡、粒子/光效、悬停/点击反馈，特效要服务信息、不干扰操作；优化布局、可读性与流畅度；各尺寸响应式良好且性能稳定。

本文覆盖 V2 第 2–3 节（token 与组件）。V3 的锁屏骨架、翻页器与断点结构保留。

---

## 1. 规则

1. **token 是唯一来源**：颜色、字号、间距、圆角、阴影、动效时长与曲线、层级只在 `:root` 定义。组件只引用**语义层**（`--c-*`、`--k-*`、`--q*`），不直接写十六进制色值。唯一例外是 SVG 美术类（`.sb-*` `.pt-*` `.ep-*`），它们引用**美术层** token。
2. **特效必须携带信息**。每个动效都要回答"它告诉玩家什么"，答不出就不加（见第 6 节）。
3. **动效只用 `transform` / `opacity` / canvas**，不改布局；入场位移只朝上、朝左右，或者缩小，**不能增加分页区域的 `scrollHeight`**，否则会触发 500ms 溢出巡检的重排循环。
4. **减少动态效果**（`prefers-reduced-motion: reduce`）时，CSS 关闭全部动画与过渡；`app.js` 的粒子、飞入、涟漪、突破演出和槽位过渡都按 `reducedMotion()` 跳过。信息本身（数值、文字、颜色）不丢。
5. 不新增静态文件，不请求外部资源。字体只用系统字体栈，图标是内联 SVG sprite 或 CSS mask 的 data URI，纸纹是内联 SVG `feTurbulence`。

## 3. 字体与字号

| 角色 | 栈 | 用于 |
|---|---|---|
| 展示 `--font-display` | 楷体栈 | 页名、匾额、页签、导航、境界、对话框标题 |
| 标题 / 数值 `--font-serif` | 宋体栈 | 事项名、道号以外的标题、全部数值（`tabular-nums`） |
| 正文 `--font-sans` | 系统黑体栈 | UI 与正文 |

字号阶：12 / 13 / 14 / 16 / 18 / 22 / 28，入道标题用 `clamp(32px, 6vh, 54px)`；最小 12px。行高：标题 1.25，正文 1.55，阅览 1.75。小标（kicker）字距 .12em。

**层级（自上而下）**：匾额（楷 22 金字黛底）> 页签（楷 18）> 区块标题（楷 18，左侧金色竖条）> 事项名（宋 16 粗）> 正文（黑 13–14）> 注（黑 12 辅助色）。

## 4. 间距 · 圆角 · 阴影 · 层级

- 间距（4px 基）：`--sp-1…9` = 2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32。卡内 8–12，区块间 8，面板内边 12，对话框 20–24。
- 圆角：`--r-xs 4`（印、徽标）· `--r-sm 6`（输入、小块）· `--r-md 10`（卡片、按钮）· `--r-lg 14`（面板、对话框）· `--r-pill`。
- 阴影：`--e-1` 卡片静止 · `--e-2` 悬停 · `--e-3` 浮层与对话框 · `--e-panel` 面板（发丝线 + 内高光 + e-1）· `--ring-focus` 焦点环（2px 底色间隔 + 2px 石青）。
- 层级：`--z-raise 2` < `--z-overlay 20` < `--z-popover 30` < `--z-mast 40` < `--z-fx 70` < `--z-notice 80` < `--z-modal 90` < `--z-replay 95`。

## 5. 组件

### 5.1 按钮（四级 + 锁定）
| 级别 | 选择器 | 外观 | 用途 |
|---|---|---|---|
| 主 | `.primary-button` | 朱砂实色、内高光、3px 下沿；悬停上浮，按下下沉 | 入道、确认不可逆操作、返回战场 |
| 推荐 | `.world-submit.primary-button`、`.action-button.primary` | 石绿实色 + 泥金描边环；悬停金色外光 | 后端 `primary` 标记的推荐事项 |
| 次（柔） | `.secondary-button`、`.world-submit`、`.action-button` | 石绿浅底、深绿字、细边 | 日常事项默认；战斗类事项自动换为朱砂浅底 |
| 幽灵 | `.text-button` `.small-button` `.chip-button` `.tool-button` `.pager-button` | 象牙底胶囊 / 方钮 | 次要工具、翻页、页头存读 |
| 锁定 | `:disabled:not(.is-pending)` | 凹陷底、虚线边、灰字、无位移；事项钮带锁形图标 | 条件未满足（原因写在卡内朱砂行） |

- 事项卡按钮只显示短动词「施行」（战斗类为「出手」），完整事项名放在 `aria-label`，读屏仍会读出原名；带字段的表单提交钮保留全名。
- 进行中：被按下的按钮加 `.is-pending`，按钮内转圈、`aria-busy="true"`，失败或成功后移除。
- 点击：`pointerdown` 时在本身裁切溢出的控件里插入 `.ripple` 涟漪，520ms 后移除。
- 触控：<760px 时所有按钮与 summary ≥44px。

### 5.2 事项卡 `.world-action` / `.action-row`
左侧 28px 类别字牌（`::before`，颜色与字形由 `--kind / --kind-soft / --kind-glyph` 决定）、名称（宋 16 粗）、耗（凹陷底）/ 得（石绿浅底，最多 2 行）、锁定原因（锁形图标 + 朱砂字，最多 2 行；手机 1 行），右侧行动钮。悬停：上浮 1px，阴影升到 e-2，边框染上类别色。可执行与锁定两种卡面明显不同（白卡 / 宣纸底 + 字牌去色）。带字段的事项点开后，在事项区内以浮层表单展开（`sheet-in`）。

### 5.3 面板与页签
面板 = `--c-surface` + `--e-panel` + `--r-lg`。舞台页签与卷宗页签选中时：泥金下划线由中心伸展（`scaleX`）、文字转为黛青；计数徽标选中时变为石绿实色。玉牌导航：悬停时玉牌轻微上浮放大，选中为黛青描金底并带左侧金色指示条（`scaleY` 弹出）。

### 5.4 槽与数值
`.meter` 带内阴影轨道和上半高光。减少时，泥金残影（`.meter-ghost`）延迟 0.35s 再缩回，显示**本次损失量**；增加时残影先到位，填充随后追上。气血低于 30% 时 `.low` 慢速闪烁。筹码类资源（修为、灵石）是带金珠的胶囊。数值变化时出现飘字（+绿 / −朱）。

### 5.5 反馈层
| 组件 | 位置 | 行为 |
|---|---|---|
| `#notice` | HUD 下方居中（`max(--hud-h, --mast-h)`），**不再遮挡资源** | 按类别显示 信息 / 成功 / 错误 图标；成功回执 6 秒后自动收起，错误与待确认常驻 |
| `.toast` | 右上，HUD 以下 | 新增日志至多 3 条；底部进度条显示剩余停留时间；`aria-hidden` |
| `.save-status` | 页头 | 状态点：已保存 绿 / 落笔中 蓝闪 / 待确认 琥珀闪 / 未开始 灰 |
| 对话框 / 阅览 / 战报 | 居中 | 背景虚化 2px；弹簧曲线入场；战报适配一屏（舞台按视口高度收缩，日志只露出最新几拍、顶部渐隐，回看用时间轴） |

## 6. 特效清单（每一项都说明传达的信息）

| 特效 | 触发 | 传达 | 实现与预算 |
|---|---|---|---|
| 舞台灵气粒子 | 常驻（舞台 / 入道页可见时） | **当前境界**：颜色 `--aura-n`、密度和上升速度随九境递进 | 单个 canvas，8–46 粒，DPR ≤1.5，**30fps 上限**；标签页隐藏、舞台不可见或减少动态时停帧 |
| 获得飞入 | 写操作成功且资源增加 | **收益从哪个事项来、进了哪项资源**：粒子从被执行的卡片飞向增加的 HUD 资源，到达时资源脉冲 | 全屏 fx canvas，只在有粒子时运行，空闲零开销 |
| 事项金光 | 写操作成功 | **刚刚执行的是哪一项**（重渲染后仍能定位） | `box-shadow` 动画 1.4s |
| 按钮转圈 | 请求进行中 | **哪个操作正在等待服务端确认** | CSS 伪元素 |
| 点击涟漪 | 按下任意可点控件 | **按压已被接收** | 控件内 span，520ms |
| 槽位残影 / 低值闪烁 | 气血、灵力、敌方血量变化 | **这次掉了多少**，以及**危险** | 宽度过渡 + 延迟残影 |
| 资源脉冲 / 飘字 | 数值变化 | **变化量与方向** | transform |
| 页签切换 | 切换页签 | **内容区已换** | 面板 opacity + scale(.992) 200ms |
| 翻页 | ‹ › / 滚轮 / 滑动 / PageUp/Down | **翻页方向** | 区域水平滑入 14px（`turn-next / turn-prev`） |
| 场景切换 | 切换卷目 | **到了另一处** | 横幅淡入 + 匾额与说明依次从左滑入 |
| 突破演出 | 境界文本变化 | **境界提升** | 双环扩散、匾额弹出、64 粒金色爆散、HUD 境界印闪光，1.6s |
| 品质光晕 | 极品徽标 / 槽 | **稀有度** | box-shadow 呼吸 |
| 敌方呼吸 / 首领光环 | 对峙中 | **敌人仍在场**、**首领** | transform / 旋转虚线环 |

## 7. 布局与响应式
骨架沿用 V3：顶栏 44 · HUD · [玉牌栏 76 │ 舞台 + 页签 + 内容 │ 卷宗 clamp(240,22vw,300)] · 潜修状态栏 40。尺寸以 `--nav-w` `--aside-w` `--stage-h` `--tab-h` `--bar-h` `--gap` token 表达，断点只改 token：
- ≤1279：玉牌栏 62，卷宗 clamp(220,26vw,260)。
- ≤1023：页头存读三钮只留图标（文字视觉隐藏，读屏仍可读），对峙改为两行。
- <760：存读三钮成为 44px 图标钮并入 HUD 行；潜修条在 HUD 下；舞台 64（战斗 120）；底部 2×6 玉牌；页签末尾为「卷宗」。
- 矮屏 ≤760 / ≤640（桌面）、≤620（手机）逐级压缩舞台、页签、翻页栏，序章舞台在矮屏收起地点说明以免与目标条重叠。
- 战报对话框按视口高度收缩：≤760 舞台 32vh、日志 3 行；≤560 舞台 24vh、日志 2 行。

## 8. 兼容与可访问性
- 全部原有 id、`data-world-page` / `data-action-key` / `data-group` / `data-stage-tab`、表单 name 保留；新增 DOM 只有 `.tool-label`、`.btn-label`、`.meter-ghost`、`.ripple`、两块 canvas，以及页头 `data-state`。
- 页头存读按钮由「图标 + `.tool-label`」组成，`app.js` 只改 `.tool-label` 的文字。
- 焦点：`:focus-visible` 统一为双环（底色间隔 + 石青）。
- 读屏：事项钮 `aria-label` 为完整事项名；进行中按钮 `aria-busy`；成功回执自动收起后，`#notice-text` 文字仍保留。
