# R5 独立QA质疑与可测验收提案

状态：需求交叉评审，尚无R5实现通过结论。仅改本文件，不改应用、配置、既有181测试或玩家档；待PM冻结后实施独立测试。依据AGENTS、R4_DESIGN/API/TESTING、当前rules/world/loot/cadence及实例配表。R4完整验收作为回归起点，不证明新图形/自动/CD能力可用。

## 1. 先把“看起来自动”与真正玩法分开

当前核心是确定性行动回合：world每条合法指令结算一回合，敌常击→蓄势→重击；强攻耗24灵力、防御回6；丹/符消耗、毒/盾/汲灵都在同一权威结算中。副本三战间可免费静养，满血蓝服丹会拒绝；世界Boss是12条有效玩家指令的评分窗口，不是12秒。前端动画不能偷偷替代这些规则，也不能只用定时器把敌HP画成0后发奖励。

建议冻结的第一条验收：相同合法起点、相同策略与有效指令序列，正常速度/快进/关闭动画应有相同战斗结果、资源与权益；请求次数不同不自动等于玩法tick不同。是否一次请求结算多回合由架构决定，QA不预设字段，但必须能复原每次权威指令及其结果。仅动画时间、展示游标、网络延迟可不同。

## 2. 需策划和PM先裁决的五项

1. **自动作用范围与停止点。** 是仅当前战斗，还是当前三战副本？不得默认自动开启下一次正式run/下一层/下一Boss。下一副本消耗信用；确认“自动一次”不能变成无人值守无限练习刷普通灵石材料。推荐首轮默认只完成当前承诺的战斗/副本，结局、败退、需要选择或资源不足时可见停止。
2. **技能CD计时单位及首次可用。** 推荐以权威回合而非浏览器秒计；若定实时CD，需另定离线/暂停/时钟回拨规则。冻结“第n回合使用后，哪个第m回合再次可用”、控制跳过/服丹/防御是否走CD、战间是否重置、退出重进是否重置。不能一方按玩家指令、一方按敌出手减CD。
3. **消耗授权。** 自动是否允许吃丹/焚火/护身/镇魂，保留几份，模拟演武与真实战斗的库存口径不同。推荐明确开关/上限、默认不擅自耗稀缺符；不可把“自动会必胜”当作无条件承诺。
4. **持续/爆发法宝取舍。** 现本命战力宝加攻击、护持战力宝加最大气血，修炼型只增速；未定新属性不能先写死伤害表。新增爆发不应无偿叠在旧攻击百分比上使旧构筑失去选择。须给等品质/章数/强化、同预算时的短战/长战/护盾/12回合评分对照，至少各有可说明的优势场景，不要求两者每场等强。
5. **旧档影响范围。** 序章、free、longline和进行中battle是否都用新CD；旧技能等级/法宝UID如何映射，旧缺字段如何保守补齐。不能删旧battle或免费重置Boss已用回合/副本预约解决迁移。

## 3. 自动策略的具体软锁反例

| 实际起点 | 失败策略反例 | 冻结后必须验证的结果 |
| --- | --- | --- |
| 灵力不足24，强攻在CD | 总选强攻→422→原请求循环，战斗永不前进 | 策略只提交当前合法动作；有普攻/防御降级，拒绝不得热循环或吞回合 |
| boss已可普攻一击击杀，己方低血且敌将重击 | 先吃丹/等CD反被击杀 | 至少存在公开可解释的收尾优先规则；不把策略败北当产品必败，但可选策略不能宣称保命却忽略必胜收尾 |
| 残毒1遇重击，或残毒2+镇魂 | 以“敌没出手”跳过旧毒，或刷新2后立即扣成1 | 保留旧毒先跳、存活后新毒2；丹先清免新，防只免新，镇魂旧毒仍跳；动画图标与结算一致 |
| 星塔0MP、强攻CD未到 | 无限防御/补蓝、不普攻，敌可能已可击杀 | 有界回合推进与明显停止/策略说明；不能蓝0就停止整个游戏或继续耗丹 |
| 熔炉残盾小于攻击，背包火符1 | 脑补火符破盾溢出、本体伤害翻倍 | 保留物理溢出/火符专破盾不溢出的真规则，显示吸收与本体伤害分开 |
| 副本一战结束，残血/丹0 | 立即开下一战，忽略原免费静养；或静养计作新信用 | 战间策略先后由策划冻结；免费静养不消耗额外信用/伪造通关，允许暂停并恢复 |
| NPC丹师有两次回血，玩家低伤 | 以“HP没下降”判死循环自动逃跑或无限跑 | 死循环判定考虑有限回血/CD/毒等未来变化；设有界执行上限后安全暂停，不能凭单回合无伤宣判 |

上述是待定策略的验收反例，不强制所有构筑自动通关最高难。最低保障是合法、不重复消耗、能暂停、不会永久卡住后续手动玩法。

## 4. 全部战斗类型兼容门槛

不是只演示副本妖兽。序章有独立attack/power_attack/defend/use_pill/flee规则（强攻6MP），世界则含wild、guard、secret、dungeon、arena、regional、escort、world_boss、elite共九类；必须逐类明确支持自动/仅手动的UI提示与实际入口，无静默失效。

- 序章三关仍真实通关，旧53动作若设计变更需另解释，不随意弱化既有规则验证。
- 守关仍满足真实胜利与突破门槛；秘境/护送保留原上下文，结束不误跳副本层。
- 三战副本：预约始终仅一次；自动手战胜利能否算manual必须PM裁决。建议区分“实际逐回合战斗”与既有快捷，自动实际战斗可算实战，但不能将快捷回放伪造成s6手战证明。
- 演武/三域依旧明确NPC模拟，药品使用走模拟库存，不覆盖战斗期间拍卖真实到账；自动败退不能污染真实HP/MP或奖励多发。
- 世界Boss严格12有效指令、每日最多3次正式尝试、best单次个人伤害/F(best)-paid。CD等待/动画帧/GET不算指令；第12回合结算后不得再追加爆发。玩家法宝主动/追击/持续伤害的评分归属要冻结，NPC不计、盾吸收不冒称本体有效伤害、过量不计，旧零伤参与与故事s7正伤口径仍不同。
- 三精英仍仅对应已接故事可打、胜利只记故事进度；自动不能凭地图点击跨段领奖或重复发器物。

## 5. 法宝/CD的独立数值证据

策划冻结后QA以独立逐回合算式对照实际engine，不从实现生成同一预期自证。至少测首回合爆发、临近战斗结束、CD差1、敌被控、玩家被耗蓝、持续伤害最后一跳致死、双方同回合濒死、盾破/未破与Boss第12回合。明确“持续几回合”是施加当回合是否跳、叠加/刷新/覆盖规则、战间/跨敌/退出后的清理。

对比同预算持续型/爆发型：小怪短战、三主题D2/3末Boss、精英、世界Boss各记录回合、真实消耗、HP/MP、个人评分、信用和装备收益。若自动策略变化使最高Boss伤害/高难装备取得速率明显提高，需量化经济后果，不只检查动画好看；保持修炼加成总15%与无活动直接XP旁路，不能让伤害proc隐式提高持续修炼。

## 6. 并发、恢复与权益故障矩阵

定义一个实际最后一击/第12回合/三战最后一敌作为事务故障点：state更新后requests写入触发失败应全部回滚；同ID重试一次落地，丢响应→刷新续试不能重复出手/药耗/掉落。两个标签不同ID同revision只有一个提交，另一方刷新到权威态；旧battle被新局替换后旧自动计时器不能攻击新battle。

正常/快进时分别在：指令已提交未响应、动画中、战间、最后奖励待展示时刷新/关闭页/停服重启。恢复应保留真实HP/MP/CD/持续状态、Boss次数与命令游标、信用预约及pending权益；未完成副本失败退款只能一次，已胜不得退款。恢复是继续权威进度，不回放并再结算已执行指令。长线位置checkpoint不得返还战损/消耗/CD/已花信用或重生已分解法宝；free原回档能力若保留须与全局去重账本一致。

## 7. 图形场景与推进图必须传达真状态

战场至少可辨玩家/敌方、双方HP/MP、下一招、当前回合、CD不可用理由、毒/盾/耗蓝状态、自动开关/暂停、消耗策略。数值/文本为可访问替代，不只靠颜色、粒子或canvas；自动动画展示中的旧HP应标记回放/同步状态，新的权威结果不能被动画结束回调覆盖。

副本推进图须对应真实三场节点：未解锁/可前进/当前战斗/已胜/失败撤离可区分，不能点击未过节点跨难/章或直接领末奖；两场胜后退出不画全通关。战间静养与下一战实际入口可达，正式/练习/快捷清晰，不把快捷动画宣称新手战。

320px与桌面均真实点击全部控制；键盘可启动/暂停/手动接管、焦点不被逐帧重建、减少动态效果模式可用。自动刷新不替换尚未提交表单或强抢焦点；屏幕阅读器不得每动画帧刷长日志。快进、关闭效果、失焦不改游戏收益/回合；用户能在有限一条在途指令后暂停，不能“点暂停”又偷偷执行剩余整场。

## 8. 冻结后执行与证据门槛

先补权威规则与时间/恢复反例，再做全战斗种类公开路线，最后真实Chromium验证场景/推进图/自动操作与后端快照逐步吻合。保留181项有效旧测试；获批规则确实变化时只调整相应独立预期并记录原因。新增单元/真实HTTP/浏览器三层证据不能互相冒充。

正式完成须有：默认新长线与旧free/旧长线（含进行中9类世界battle及序章）的兼容；至少一条不用状态注入的序章→低难→三主题高难/精英/Boss公开路线；自动/手动同策略对照、正常/快进/无动画对照；断网/多页/重启/事务失败；桌面/窄屏/键盘与减少动态效果；最终完整回归、实际发行包独立解包。证据注明受控边界fixture与公开可达路线区别，不把模拟自动战斗耗时等价真人体验。
