**隐藏几何推定（不得视为精确数据）：** 梁架内构不建（屋檐下以斗拱带+额枋表达）；门窗数量按开间均分；屋面曲率用 `y = h·v^1.7` 下凹曲线+角部起翘 `2.2m`；台基埋深以山体包住；建筑背面按正面开间对称推定（B04/B05 用独立背面图意图：后墙封闭、长屋脊）；洞府只做洞口与浅洞腔，不做内部；碰撞用建筑包围盒+山体高度采样，不做步行通道。

## 5. 交互方案

- 默认机位：南侧高空，看向主殿-山门中轴（俯角约 28°）。
- 自定轨道相机：左键/右键拖拽环绕、滚轮缩放（距离 120–900m），俯仰 12°–72°；相机点每帧对地形高度场+建筑包围盒做推离，最低高度 y≥40（不入云）。
- 「回到默认视角」按钮 + 快捷键 Home。
- 拖拽/点击判别：按下后移动 > 5px 或 > 350ms 视为拖拽，不触发拾取。
- 点击建筑：相机平滑聚焦（0.9s 缓动）后打开对应卷目面板；悬停：轮廓高亮（postprocessing OutlineEffect）+ 名称提示。
- 入口标记：DOM 标签按三维投影定位；背面/被山体遮挡（射线检测）时淡化；屏幕边缘夹紧；标签间按优先级做简单避让，过近者隐藏次要标签。
- HUD/面板 `pointer-events` 独立：场景只接收落在画布本身上的事件，面板打开时场景暂停渲染且不接收输入。
- 氛围动画克制：云海/瀑布/灵泉缓动，`prefers-reduced-motion` 时停止相机过渡与粒子。

## 6. 性能风险与对策

| 风险 | 对策 |
| --- | --- |
| 绘制调用过多（构件逐个 Mesh） | 每栋建筑按材质合并几何（mergeGeometries），栏杆/斗拱/松树/石灯 InstancedMesh；目标 <300 draw calls |
| 三角形数 | 屋顶网格分段 12×8；远景低面；目标 <1.5M 三角形 |
| 透明叠加（云团） | 云团数量按质量档 60/30，软边、深度写关闭 |
| 后期处理 | 仅 Outline + 轻度色调；低档关闭 Outline，改为发光提示 |
| 双 WebGL 上下文 | 宗门模式下不挂原舞台氛围；战报回放打开时宗门暂停渲染 |
| 资源泄漏 | `dispose()` 遍历释放几何/材质/贴图/合成器，`renderer.info` 记录前后数值 |

## 7. 验收方法

`tests/browser_sect3d.py`（Playwright + 本机 Edge，1920×1080，deviceScaleFactor=1）：
1. 真实账号按公开路线进入凡界，断言 HUD 数值与 `/api/state` 一致（名号、境界、灵石、药草、攻击、修为%）。
2. 南侧默认、东侧、西侧、背面（北）、高空五视角截图；记录 FPS、draw calls、三角形。
3. 拖拽后不触发拾取；点击建筑打开对应卷目；Dock/右侧/任务「前往」打开同一卷目；面板内点击不旋转场景。
4. 测量 HUD 图标与正文字号、面板边界不超屏、标记互不重叠。
5. 相机极限：最大俯仰/最小距离/最低高度，断言相机不在山体内与云层下。
6. 强制禁用 WebGL（`?no3d=1` 调试参数 + 模拟失败），断言降级图录可用并能打开卷目。
7. 退出登录/切换时 `dispose`，记录 `renderer.info.memory` 归零。
未运行的项在验收报告中标“未运行”。
