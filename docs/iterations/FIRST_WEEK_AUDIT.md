# v1.1.0首周与后期节奏审核

历史审查：本文针对调整前的v1.1.0。用户随后已授权R4落地，当前规则见[R4设计](R4_DESIGN.md)，实际验收状态见[R4测试](R4_TESTING.md)；以下保留原始审查事实。

结论：**部分满足，不宜宣布已达到新增体验目标。** 已具备持续成长与真实装备/活动循环，但首周境界和地域拓展偏慢、同日回流缺少恢复的新装备机会，后期手动日常尚未减负。本轮只审查，不修改应用、数值、玩家档或已交付压缩包。

用户目标为前一周进度稍快且内容丰富，每天可以多次上线推进、领奖、获得装备，之后转向日常与挂机。由主策划主动审查、QA独立复现、PM交叉核对；功能测试通过不等于体验节奏满足。

## 现有规则与判定

| 目标 | 实际规则/证据 | 判定 |
| --- | --- | --- |
| 首周较快推进 | 无加成及时突破为入世后D3结丹、D7元婴；对应赤砂洲与玄潮域。前72小时通常只有青岚州。极端开局15%仍需约2.61/6.09日，且假设守关/材料已齐 | 有前快后慢趋势，但首周推进密度偏低 |
| 首周内容丰富 | 现有三洲、三秘境、三副本各三难度、12四艺配方和有限主支线；多数建设/宗门/社交可集中推进，未形成七天持续释放的新目标。NPC交互和宗门加入不按所属地域阻挡，不能冒称这些是逐日新开放内容 | 系统齐备，分层投放不足；尚无真人首周内容时长证据 |
| 多次上线仍能得到新装备 | 副本所有章节/难度共享UTC日3次成功掉落，可首会话全用；间隔8/16小时不恢复。可拆成多次完成，但做完再回来没有新增正式掉落资格 | 回流价值弱，需要调整 |
| 多次领奖有推进意义 | Boss每日最多3次尝试，仅更高best产生差额；低分不再发。日常三选一最多一份，周主题一份，均可集中完成 | 有改善构筑/成绩的价值，缺少随时间恢复的新增奖励机会 |
| 后期清日常与挂机 | 修为在线离线持续，待突破不停；洞府/派遣/经济按行动推进。三次副本即9场手动战斗，另有Boss/准备/整理，无扫荡或快捷复打 | 修为挂机满足；操作减负不充分 |

额度用完不等于完全无收益：重复副本仍有灵石`10×难度`、地域材料3，首通也有灵石与灵晶；缺少的是新的实例装备和该轮宝尘/强化材，不可写成所有奖励清零。主线、首次通关、建设、社交和小境界也能分次推进，只是没有保证次次回流都有新的上述机会。

现有装备是固定五模板轮换和确定性品质保底，奖励可预测，没有随机词条或稀有装备池。用户的“爆装备”可以包括现有真实掉落；若期待反复挑战时的惊喜和不同构筑收集，当前深度仍不足，不能靠多显示掉落按钮证明满足。

## 独立证据

- `FIRST_WEEK_DESIGN_AUDIT.md`：主策划按真实地域/境界/活动条件审查，不把菜单数量当每日内容量。
- `FIRST_WEEK_QA_AUDIT.md`及`../../artifacts/r3-qa/first-week-audit.json`：QA隔离Store、注入UTC，重现首会话三次正式掉落后8/16小时没有恢复；修为仍增长，D3/D7手动准备条件后推进境界。这不是对应小时数的真人游玩观察。
- `../../artifacts/r3-qa/designer/designer-r3-boss.json`：先前独立合法路线429动作/注入5日做出双极品战力法宝，1078伤达到Boss顶档。此事实说明不能再以“第20日才有高阶法宝”的假设替代实际养成速度。修炼型与战力型提质成本相同，但不能一件兼得。
- `../../artifacts/balance/qa-month-r3-stages.csv`：原阶段时间模型。副本/活动均不直接奖励修为，日常清完后主境界主要等待连续成长，装备和材料能提前准备非修为条件。

## 调整优先级（建议，尚未实装）

1. **重新分配前快后慢曲线。** 主策划候选基础日数`[0.5,1.5,3,5,7,8,9,11]`仍合45日，目标为首日12小时结丹、第2日元婴、第5日化神；后期相应拉长，总修炼增益上限不变。它保留45基础日，不保留旧修为总成本。守关/丹符可达性、不同上线频率与旧档迁移仍需模拟和实际操作验证，不能直接换配表宣布完成。
2. **让隔一段时间回来有新机会。** 评估回复型挑战资格并可积攒，开局仍给充足次数；不要求固定钟点签到，单次上线玩家也能积攒后使用。主策划已撤回“初始只给1次”的建议，避免削弱首次会话。首周总产出、背包、品质保底和通关/消耗归属必须重算，不能把理论23份当已经实测的预算。
3. **补首周实际内容与追求。** 以章节首通、支线、精英挑战、不同装备方向和阶段目标分层推进，保证有真实新选择与实物奖励。早满法宝之后用章节装备与挑战接续，不随意砍收入硬拖，不用单纯签到页代替玩法。稀有掉落若引入，须公开规则、保底与权威结算。
4. **后期降低重复操作。** 已有真实胜利/熟练证明的普通关可评估快捷结算，沿用同一资格、掉落、保底、材料和事务；Boss保留主动冲分价值。解锁条件不应逼高配玩家故意拖回合。避免只把前期等待缩短、后期改成长时间手动重复。

实施影响须单独设计：新曲线版本与旧角色进度保留/迁移；回复型资格的权威余额、上次回复水位、上限与待结算run占用；前端显示剩余次数、下一次回复、可积攒容量及首通奖励。快捷结算应复用真实奖励函数与唯一凭证。不能只改日额度数字或加一个没有后端规则的领取按钮，也不能把首通和回复资源叠成无限产出。

## 下一轮验收应覆盖

- 前七日的境界、地域、任务、关卡和装备目标逐日清单；每个新目标有真实规则和入口，不只列系统名称。
- 每日一次/三次/漏登三种路线，比较实际可获装备、收益积攒与损失；初次会话不能比当前更贫乏。
- 首会话用完资格后隔数小时回来，能取得新增可用机会；跨日、回拨、重启、并发和领奖幂等不套利。
- 第8日以后日常操作数与会话实测；快捷结算不产生额外奖励或绕过难度，挂机与手动部分清楚。
- 更新后的完整月余路线、法宝取得日期、早满后的目标以及存档兼容。不把45日理论除法当新版本实际成长验证。

审核无需改变当前v1.1的功能验收事实；新用户目标需要下一轮节奏与内容迭代，不能反向宣称旧版已经达成。
