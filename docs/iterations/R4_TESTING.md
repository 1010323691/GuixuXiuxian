## 2. 第一批风险与交叉质疑

1. **预约与恢复水位最易复制资格。** T0 av3→预约1后av2/res1仍总满3，等8h再成功应av2/res0，并从成功时起恢复；不能同时把满仓期间8h补回来。等8h退出则退款至3、丢弃满仓余时。重复退出、败退/取消竞态、旧slot、重启均不得再退款。部分空仓+预约跨8h也不得超过总3。
2. **每日一次与三次收益不能混成同一“首周上限”。** 初始3、及时清信用的半开168h理论上界23；T0/24/…/144h每日一次各清3为21。漏登7日只回满3，不补21。实际入场占位/结算用时会改变恢复时机，路线必须按秒积分，不能直接按理论数填表。
3. **改曲线必须真正兼容余额与已消费。** 先结旧率、再按比例转换；例如stage0旧810/1620应成为新135/270，旧高于阈值的余额不得截到100%。旧slot不能返已花突破成本、旧request不能重新迁移/领奖；并发启动只升级一次。最终封界后的潜修储备与旧进行中战斗不能擅自重算敌人。
4. **快捷可能开出新的经济旁路。** 建议仅消费正式信用，0信用禁止快捷；普通手动练习仍可保原普通材料。若0额也可快捷，必须单独解释无限普通石材/活动计数与补给消耗的经济后果，不能悄悄加入。快捷成功可计普通完成目标，但不得冒充新的手动熟练胜利或给未通过的更高章难开门。
5. **快捷成本取舍已裁决为免费。** 奖励、保底、credit、pending、receipt仍须同事务；明确断言不扣丹药或隐藏原料。无信用时清楚禁用，原满包权益走托管的规则不能因快捷而丢物。世界Boss与精英仍需手动，不能快捷代打。此条保留讨论来源但以PM免费裁决为验收标准。
6. **故事链不是未来行为自动全清。** 七段实际目标、解锁/追溯口径、三精英与普通副本区别应冻结；非纯日历锁、晚来可补做。自选器章/质/选项绑定段落而非领奖时当前stage，未领跨阶段、满包与读档不能复制或吞掉。不得靠旧一次性craft计数让未来七段瞬间都完成，也不能迫使已完成合法首通无意义重刷。
7. **减负要测同收益，不只按钮存在。** 熟练资格不能逼玩家故意挨毒；高配直接击杀的合法胜利应能形成有效熟练。对照手动与快捷同一章/难、同3份信用、同掉落/保底结果，记录实际点击/战斗数/补给/浏览器用时；API脚本秒数不是真人用时。
