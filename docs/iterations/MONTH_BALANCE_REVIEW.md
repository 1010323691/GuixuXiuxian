# 月余成长独立审计：R3最终规划结果

历史规划审计：本文记录实装前的数值模型，不是当前运行验收。后续已实施v1.1.0，真实掉落、成长、活动、Boss和界面证据请读R3_TESTING.md及R3_GAMEPLAY_REVIEW.md；模型中的装备获取日期仍是假设，不因实装而自动变成实测事实。

本轮是数值规划与设计审计，没有修改运行游戏或既有测试。R3采用PM与策划最终裁决：持续修炼、活动主要产出装备道具、活动直接道行归零。旧R2的540基础+360活动+30额外及199170成本已撤回，不能作为本轮结论。

## 结论与适用边界

在下述掉落时机和非修为条件假设下，每日上线手动突破，普通逐步获取修炼法宝的模型为**42–45日达到凡界顶点**；从入世即有全部15%加成的理论极端为每日上线40日、精确临界上线39.130435日。结果支持“约一个多月”的规划方向，不是已实装、真实掉落可达性验证或真人游玩时长承诺。序章不自动折成额外24小时。

不必每天突破：基础持续累积不封仓，但未手动突破仍按当前境界速率增长。两天一登、错过上线或晚突破可能超过45日；完全不上线不会自动过Boss、晋境或通关。旧每日30分钟只是撤回的参考假设，不是当前用户限制。

## 当前版本为何不能承诺月份

当前自由行动版七次突破总成本1960；活动、吐纳等按行动即时给修为，没有现实时间门槛，不能据此承诺历日。`WORLD_BALANCE`已公开的独立HTTP路线A为217世界tick/271全局行动，路线B为486/540且0吐纳；均是行动可达性证据，不是耗时月余证据。只采用已更正、败退即失败后重跑的B记录，不使用曾撤回的旧PASS。

当前审计明细保留在 `artifacts/balance/qa-current-month-audit.json` 与 `qa-current-route-sensitivity.csv`；用假设点击速度换算真人时间也不能替代实测。已交付W1的76项及浏览器通过，只证明既有玩法，不证明本轮时间/装备/Boss/读档方案。

## 实际运行的连续时间模型

复现：`python scripts/simulate_month_growth.py`。工具不导入游戏、不调用服务、不改玩家档。40场景使用有理数秒积分，逐段保留余额；每场景验证累计入账=成本已付+剩余修为。结果来自程序输出，而非用总成本除平均速率猜测。

模型约定：每次计划上线先结算旧境界/旧装备，然后手动突破，再装备已经到达假设获取日的法宝。非XP关卡、材料和Boss资格均假定准备完成；获取日期只是假设，尚未验证真实掉落路线。所谓“精确临界”会增加明确的手动上线，不代表离线自动突破。“晚一轮”为达到条件后再等下一次计划上线。

## 装备—挑战—掉落的后续验收缺口

本轮只有成长积分通过，不表示装备闭环已经实现。应逐条验收：战力装备实际改变伤害/生存→多难度挑战真实可达→确定性奖励/碎片入账→制作或兑换装备→修炼装备只影响未来基础速率；高难奖励提高但不能越过修炼15%边界。不能用仅显示更高战力、没有产物使用或伪造获取日期来宣称通过。

PM最终世界Boss规则为固定12玩家回合窗口、极高HP且不提前击杀、无回血。有效伤害仅玩家本人实际伤害，不含NPC/同行、治疗或过量。固定HP击杀Boss会导致人人有效总伤害相同，不能用于该排行。

每UTC日最多3次正式挑战，按周期**最高单次**有效伤害best，而不是三次相加；期初阶段冻结，`R=450+180×stage`，最高计2R。币权益 `F(best)=2+floor(60×min(best,2R)/(2R))`，最多62；档阈值0.25/0.5/1/1.5/2R对应确定性碎片品质0–4。只发 `F(newbest)-paid`及首次跨档差额，低分重复不发。例stage0：半R首次17币、四分之一R再战0、提高到R再发15，总32，不能逐次发17+9+32。参与2币只能首次有效正式参战入账；第四次、跨UTC重试、无效伤害和断线提交的原子性仍待实现测试。

## 读档、时间与所有权独立风险

最终裁决：新profile经济、资产、装备所有权、奖励账本与现实成长不随slot回退；兼容checkpoint位置/剧情/战斗恢复，但不得重领。仅把claimed放在slot外不够：读旧背包会吞掉已领奖装备；重放奖励又可能复活已出售/分解的装备并保留转换材料，造成双份资产。必须以唯一装备实例UID、奖励/结算身份及当前所有权共同保证一致，卖出/分解后不能load复活，已领尚持有的物品也不能load消失。旧自由档保持旧完整回档语义并明确区分。

后续必须独立验证：跨slot反复load不加钱/物/修为；领奖→存档/读更旧档、分解→读档、出售→读档、背包满的待领、重复请求及不同request_id重复结算；同一事务失败不半写；战斗checkpoint不能重新发唯一奖励。时间测试涵盖秒级分拆与整段结算等价、余数不丢、时钟回拨不负增长、长离线全段、换装/突破分段、GET只预览、POST原子结算与重复请求至多一次。无后台推进不能假称自动过Boss。
