# v1.1首周节奏与多次上线：独立QA只读审计

历史审查：本文针对调整前的v1.1.0。用户随后已授权R4落地，当前规则见[R4设计](R4_DESIGN.md)，实际验收状态见[R4测试](R4_TESTING.md)；以下保留原始审查事实。

结论：**部分满足，不能宣称已经完整满足新愿景。** 现版有丰富的手动养成入口与首通/材料循环，持续修为也可靠；但首3次装备掉落能在首个会话全部用尽，隔8/16小时回来不会恢复。前3日通常停在一个地域，后期也没有副本快捷结算/自动复打，离线仅修为而非材料经济。因此“可每天多次打开”已经成立，“每次回来都有新增掉装机会”和“后期清日常后轻负担挂机”仍有明确缺口。

本轮只读现版源与既有证据，并以临时Store注入UTC做小复现；没有修改应用、配置、既有测试、正式归档或玩家档。模拟登录不等价真人游玩时长；291次公开世界动作包含大量采集/制作准备，不能换算成内容小时数。

## 3. 额度耗尽后，什么还能玩、什么没有新增奖励

- 副本可继续完整练习；普通战斗/首通或重复结算仍给对应普通灵石、基础材料，**不是全无奖励**。但共享3份用尽后无新装备实例、该档宝尘/强化材、掉落轮换及保底进度，不以无限刷次数加速修为。
- 普通劫影/野怪、宗门委托、采集制作、NPC关系、演武/三域赛、交易仍能手动推进并得到对应资源。这些循环能填充时间，但重复采集/同战斗不是等量的新剧情。
- 世界Boss最多3次正式，耗尽后当日不能再正式进入；不是Boss无限练习。未耗尽时换装/更好策略能提高best领取差额，不能保证每次有奖。
- 已领日项目不因下线8小时/重开页面恢复，未完目标可拆分多次做。周项目同理，一次会话可完成领取，也可分开；其奖励量不会随登录数增长。
- 持续修为按现实时间增，登录只是显示/结算；并未把“多点登录”当成额外XP。等到阈值后仍需手动挑战/支付条件晋境，否则按旧境界率继续攒。

这说明现版支持玩家主动安排多次上线，但缺少足以保证**晚些回来又有新的装备收益资格**的时钟机制。它更接近“每日集中三份装备+手动资源循环+持续修为”，不应宣传为已经做好多次回访爆装节奏。

## 4. 后期清日常与挂机：现有负担

想拿满副本份额，需每天3次完整三战，即9场手动战斗、3次进本/9次下一战及恢复/补给。世界Boss每次最多12指令，最多3正式；只打一场也能拿参与/对应best权益，不能把3场说成必做。日项目另需两个真实目标，但可以与副本/Boss/制作等重叠；周项目可与日常重叠。接取前行为不追溯，先做完再接仍可能需要重做；日项目也不是单纯上线点领取。

当前没有同章熟练扫荡、离线复打、自动挑战、离线材料生产/派遣/NPC结算。`game/growth.py`仅积分成长账户；自动保存不是自动玩。因此“下线后继续修为挂机”满足，“后期日常整体已经省事”未被实现或真人用时证实。用API291/418动作或程序运行秒数证明每天几分钟都不成立。

早期追求上限也要诚实：现有策划真实合法429动作/注入5日路线，已拿到双极品**战力**法宝并以两次蓄势用丹在12回合打1078伤，领2R封顶62币/8尘（`artifacts/r3-qa/designer/designer-r3-boss.json`）；原894败退证据保留。它证明可主动养成与策略变招，亦说明固定两槽品质5档/三器强化3，首周可能较早触顶某一纵向轴。不能把“双极品战力”偷换成双修炼宝15%真人Day5已完成，更不能据此保证所有玩家5日到顶。

后续还有新章节三器基础、不同品质保底、其他构筑/境界/任务；但法宝品质不随章继续升，技能/设施/灵根也多为3级。若用户要求第一周内容集中、之后放松，早满宝并非天然错误；需要明确后续主要追求是新章/新构筑还是继续重复追同上限，不能以品质数量作无限成长承诺。

若后续批准调整，独立验收至少要同时满足：

1. 首周按12小时/Day1/3/7真实合法动作记录境界、地图、新机制、首次可领内容，不靠改存档跳过条件；区分一次性新内容与重复资源操作。

3. 完成日常后的下一次上线能说明“新可领什么/还差多久/是否已满”，原有请求去重、UTC/滚动时钟、回拨、读档、重启不复制奖励。
4. 以真实浏览器记录后期固定收益所需点击/战斗数及实际用时，证明省事；离线哪些账户增加、哪些不推进清楚可见，不伪称全经济挂机。
5. 首周普通与积极两条法宝获取路线和月余封界继续闭环；不能用提前给满宝或额外直接XP把旧月度结果悄悄推翻。

本轮发现的是**新目标适配缺口**，不是撤回v1.1原范围的141用例分轮通过或最终包五项烟测；也不将审计候选冒称上线功能。正式归档与应用hash未改。
