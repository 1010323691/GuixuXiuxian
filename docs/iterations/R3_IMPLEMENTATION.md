## 已补足的歧义（实施裁决）
1. Boss只开放真实`boss_coin2→dust1`，其他兑换只有明确的`ore4+wood2→enhance_material1`四艺课业；不做空图谱/品质商品按钮。原稿“品质兑换档”落实为伤害评级与宝尘权益，品质通过真正制作/提质取得。
2. 法宝掉落保留unselected实例；`world_loot_choose{uid,effect_type}`一次选向、之后不可原物反复切属性。保底制作直接选main/guard与路径。无耐久系统，无“强化提高耐用”的假效果。
3. 全部章节固定、升级不会抬旧关敌强；难度入场冻结。全球UTC共享3次成功掉落，透明确定性模板5轮换与各难度保底，失败不推进保底；资格/receipt与所有权不回档。
4. 三器凡品可安全材料制作；强化材可低难保底或课业兑换，不能卡在先有高难装备才能进高难。
5. Boss是12玩家回合限时输出窗口，不要求击杀10^12HP靶场；只计玩家个人有效伤害，排除同行/NPC/治疗/过量，UTC最多3正式尝试，只best不sum。R=450+180×期初stage，奖励计分封顶2R；币权益2+floor(60×min(best,2R)/(2R))，最多62。仅发新best权益减已发；宝尘阈值权益1/2/4/6/8同样补差。
6. 月度预测需读取真实获得、选择、装备、提质的时间，不采用假定day3/day10直接注入法宝。新profile checkpoint不回退成长、经济、所有权、消耗和奖励资格；规则细节由架构文档落实。

## 低难到高难静态可达性审计（特色机制加入前基线，不是运行测试）

- 凡品+1三器：攻击48、气血231、MP70、强攻100。险境Boss375HP/常击37/重击62，`强强普普普普`6回合击杀，胜HP95/MP22。
- 凡品+3三器：攻击49、气血234、MP71、强攻102。绝境Boss450HP/常击45/重击75，`强→回元丹→强→强→普→普→普`7回合击杀，胜HP39/MP19。普通丹草3可制，不用稀有掉落。
- 两场小怪低于该Boss压力，每场间允许免费静养；这仅是特色机制加入前通用Boss数值。新增D2/3末场毒/盾/抽蓝后必须变招实际胜利，不能用本算式声称三副本已通过。
