# W1 开发缺口与实施评审

状态：R1 评审，等待策划与架构冻结后实施。范围依据用户完整修仙界授权及 PM 单机 NPC 模拟裁决；原短篇仅为序章，不代表新系统完成。竞技、模拟跨域与拍卖明确为 AI，不接真实玩家或外部服务。

## 当前缺口

现有代码仅有序章境界0–3、三地、确定性单敌战斗、基础材料/丹药/交易及事务存档。尚无世界势力与区域关系、灵根体质成长、后续境界、宗门师徒家族社交、四艺差异化制作、洞府秘境奇遇、副本 Boss 链、NPC竞技及跨域赛季、订单拍卖、任务分支、成就称号排行榜和动态事件闭环；不能将原20项测试沿用为这些系统通过证据。

## 数据与兼容方案

在现有完整state新增world子树，schema升级为2；legacy realm0–3、初值、公式与53行动路线保持不变。world.stage承载后续凡界结丹至渡劫，不改legacy realm取值及气血上限表。新世界属性使用自身生命/战力与资源定义，不让后续装备悄悄修改原序章战斗算式。仙界只留版本化扩展标识，不生成仙界玩法。

存储架构师负责事务性迁移current/slot并保留revision、request账本；本岗位提供迁移所需world初态及严格验证。损坏档不可用“补默认字段”掩盖。新档和v1迁移档应具有相同可达性；序章未通关也可查看世界系统，但后续境界与高阶活动明确条件解锁，避免破坏序章路线。

建议接口统一使用完整state：initial_state()仅返回world子树；migrate_v1(state)返回不修改输入的完整新state；validate(state)检查world与legacy依赖；apply_action(state,action,params)返回完整新state和事件；project(state)返回{pages,actions}。world动作使用world_前缀，rules仅委派与合并投影。所有失败保持原state、行动计数与日志不变；一次成功只增加一次行动及日志，由world/rules单一位置负责。

## 实施划分与联动

本岗位独占game/world.py及game/rules.py。策划维护world_config.py中的目录、成本、配方、境界/敌人/任务等内容；架构负责storage/server/migration；前端与QA维持各自所有权。先冻结稳定内容ID与参数，再并行实现，禁止在不同岗位复制公式。

| 闭环 | 必需可观察联动 |
| --- | --- |
| 修炼与世界 | 灵根/体质/功法影响世界修炼或战力；突破花可再生资源，解锁地点、配方、敌人；有明确凡界终点 |
| 社会与叙事 | 宗门贡献/师徒历练/家族关系推进可执行任务和奖励，不只显示名单；关系变化触发后续反馈 |
| 四艺与经济 | 采集获取原料→配方制作→成品实际使用/装备→贡献/交易；丹器符阵各有不同效果与消耗 |
| 秘境与Boss | 世界活动取得材料与剧情旗标；副本分段推进，消耗/失败/退出有确定规则，Boss掉落用于成长 |
| 洞府与动态事件 | 投资洞府产生按行动结算的有限收益；规则AI按明确周期触发事件，有选项、结果及可持久化解决状态 |
| NPC竞技与跨域 | 明示AI对手、公开战力/结果规则；挑战有次数或轮次推进，排名及奖励与成长相连，不伪称真实在线 |
| 拍卖与市场 | 挂单扣除真实物品/资产，AI成交或退回，有查询与结算终态；不可无限重复领奖或凭空刷钱 |
| 长线反馈 | 任务完成一次领奖、成就/称号条件检测、称号实际效果、榜单含NPC和玩家；奖励幂等随同事务提交 |

## 技术风险与处理

1. **跨系统数值与卡死（高）**：材料必须有免费或可恢复获取路线；任务消耗不能永久抢走突破必需品。投影给出缺口及前往途径，QA跑零资源恢复与完整凡界路径。
2. **状态膨胀与巨型分支（高）**：内容从配置读取，动作以小处理器/公共校验组合；避免一套按钮对应一个特例。列表日志设上限，动态事件与订单必须终结及清理。
3. **重复扣费/领奖（高）**：全部world动作沿用revision+request_id与SQLite事务；自动奖励在同一次状态转移写标记，不由GET结算，不新增绕过去重的端点。
4. **迁移与手动档（高）**：current和slot都迁移；迁移失败整体回滚。旧请求重试应返回新schema最新快照，不能回放旧schema载荷产生重复奖励。
5. **假完整（高）**：每一系统需要“获取→操作→消耗/结果→保存恢复”的证据，不将静态介绍、未接通按钮或仅看板视为实现。
6. **界面动作数量（中）**：投影pages按领域分区，行动含page ID、成本收益、条件与禁用原因；只展示相关目标，减少全目录堆积，原view键保留。
7. **单机模拟可信度（中）**：AI状态由行动时钟推进、可复现且持久化；无真实时间/联网伪装。UI清楚说明NPC及AI模拟，跨域不创造隐含服务依赖。
