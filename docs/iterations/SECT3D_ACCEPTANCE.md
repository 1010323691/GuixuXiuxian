## 场景覆盖（阶段2样板范围）

**推定而非实测**：所有坐标、标高、开间数、屋面曲率（`y=h·v^1.7`+角部起翘）、斗拱间距、台基高度、桥墩、洞腔深度均为本轮推定；梁架内构、室内、碰撞通道未建。参考图像素未换算为工程尺寸。

## 与概念图的差异（按现行规则处理）

- 概念图「战力 28,640」：接口没有战力数值，HUD 显示人物页真实「攻击」。
- 「领取收益」：现行长线规则在线离线持续增长、无需领取，不新增该按钮；托盘显示真实速率（修为/分）与距突破百分比。

- 「灵药」改为真实物品「药草」；宗门贡献取宗门卷「可用贡献」。

## 既有浏览器套件回归

第一次运行 `python -m tests.browser_all`：`browser_smoke`、`browser_fx3d_real` 通过；`browser_world`、`browser_r3`、`browser_r4`、`browser_fx3d` 失败。原因是这些套件直接点击常驻工作台、断言旧顶栏与潜修栏可见，而宗门模式下工作台改为功能面板。处理：

- 产品侧：潜修栏（含「潜修详情」浮层）不再在宗门模式隐藏，而是随功能面板出现、贴在面板底边，避免功能缺失；卷首三维氛围（fx3d 舞台）在面板打开时挂载、合上即释放，宗门场景同时暂停渲染。
- 测试侧（未删除任何断言）：`BrowserWorldDriver` 增加 `open_panel()`，像玩家一样经 HUD 入口打开面板；`visit()` 与进入凡界后自动调用；`browser_world`/`browser_r3` 刷新后先回到宗门主界面再开面板；`browser_fx3d` 无 WebGL 段落改为断言宗门图录与新 HUD 可见、经 Dock 打开洞府后再点原卷目按钮。

随后 r3 的 `.r3-comparison` 因面板过矮高度为 0，改为面板打开时隐藏 Dock、面板下沿贴底（让出潜修栏）。修正后在最终代码上重跑：`browser_all` 6/6 通过，`browser_sect3d` 47/47，`tests.parallel` 435 项通过。

## 修复：叠加提示压住「返回宗门」（2026-10-21 追加）

问题：面板打开时，写入后的右上叠加提示（`.fx-layer .toast`，最多 3 条、3.2 秒消失）浮在面板上方，压住面板右上「返回宗门」按钮与右栏内容，也遮挡右上活动入口。

处理（仅 `static/styles.css`）：面板打开时提示层从资源条下沿（64px）开始，提示宽度限制在面板右侧留白内（`--sect-gutter`：>1500px 视口为 `(100vw − 面板宽)/2`，1100–1500px 为 170px），字号 13px；≤1100px 视口无留白，提示从面板标题行（112px）以下开始，不压按钮，但会盖住面板内容一角，属 PC 基线外的窄窗口。

验证：`browser_sect3d` 新增断言「写入后提示不压「返回宗门」与面板，按钮可点」（真实写入后 3 条提示，与按钮/面板相交 0，按钮中心 `elementFromPoint` 命中按钮），48/48 通过；另用临时脚本注入 3 条提示检查 1600×900、1366×768、1280×720（与按钮、面板相交 0、无出屏），1024×768 与按钮相交 0、与面板相交（如上所述）。`tests.parallel` 435 项通过。`browser_all`：首次与 `tests.parallel`（16 进程）及临时脚本同时运行，r3/fx3d/smoke/fx3d_real 通过，browser_world 与 browser_r4 在约 206 秒同时报 `TargetClosedError`（浏览器进程被关闭，非断言失败）；停掉其他负载后单独重跑 `python -m tests.browser_all world r4`，两套均通过（102s / 133s）。

## 改版：原工作台退役为右侧小窗（2026-10-21 追加）

用户裁决：不再需要原整屏工作台，入口全部下放到三维场景界面，点开后以小窗显示详细内容。

**行为**：一次只开一个小窗，位置在玩法栏左侧（1080p 下为 844–1724 × 104–894），不压任何 HUD 面板。小窗打开时场景不再暂停：可以继续拖拽、点建筑、用 Dock 或快捷键切换卷目。镜头投影会左移，让聚焦的建筑落在任务追踪与小窗之间的空地上，入口标记也避开小窗。HUD 入口打开卷目时，镜头同样飞向对应建筑。卷宗、潜修、旧事小窗按一次 Esc 即合上；卷目小窗里如果有展开的事项卡，先收卡，再按一次 Esc 合上。小于 1100px 的窗口（小桌面窗口）里，小窗铺满资源条以下，活动入口收为设置按钮下的竖列。写操作仍只经原事项卡的提交、确认与同步流程。

**改动文件**：`static/index.html`（小窗标题栏，新入口）、`static/styles.css`（小窗与各视图样式，提示/反馈位置）、`static/sect_hub.js`（视图管理、入口接线、画面让位、Esc）、`static/app.js`（宗门模式下卷宗不并入窄屏页签；卷首氛围只在卷目视图挂载）、`src/sect/index.ts` + `static/sect3d.js`（`setViewShift` 投影平移）。
