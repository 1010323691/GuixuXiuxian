在线、离线同速增长修为，待突破也不停产。主动副本、活动和故事主要产出装备、法宝、材料，不直接发修为。成长从入世开始，短序章不计时。

## 多次上线与装备机会

长线副本装备资格入世初始3次，每8小时恢复1次，最多积攒3次。界面显示可用、进行中预约与下一次恢复。到满额不积攒隐藏恢复时间；UTC跨日不额外发3次。每天一次可以积攒后集中消耗，多次上线可以及时使用已恢复的机会；漏登不会停止修炼，但装备机会只存到容量。

手动入场预约资格，成功才消耗，失败或退出归还。零资格可手动练习，仍有普通通关材料，但没有新的副本实例装备、正式宝尘/强化材或保底推进。正式掉落沿用五模板轮换和分难度品质保底，尚无随机词条池。

## 首周七段故事

推荐日只提示成长顺序，不是签到锁；按境界及前段领奖解锁，可补做，不失效。先接取再行动，过去的行为不追溯。

| 故事 | 目标 | 核心奖励 |
| --- | --- | --- |
| 百工护身 | 制造器物、完整副本通关 | 强化材与药草 |
| 商路将开 | 两次同道交流、一次实际委托交付 | 矿、木、灵晶 |
| 炉甲拦路 | 完整秘境、战胜商路炉甲 | 下品第1章三器自选 |
| 符阵同行 | 制成两符、实际启用阵法 | 强化材与灵晶 |
| 毒潭守卫 | 战胜毒潭守卫、实际服丹 | 中品第2章三器自选 |
| 再铸新器 | 手动通关难2或3、制造器物 | 强化材与药草 |
| 星桥试阵 | 战胜星桥执阵者、有伤正式Boss结算 | 上品第3章三器自选 |

三器奖励可选灵刃、玄甲或灵佩，章数和品质按故事固定，不随延迟领奖变高；不耗副本资格、不推进副本保底。精英胜利推进故事，奖励在完成故事后统一领取，不可反复刷精英领装。

商路炉甲需要破盾；毒潭守卫可防重击避毒、用丹清毒；星桥执阵者需要在输出与保蓝间取舍。免费撤退、采料、制丹符、静养后可再试。故事不要求故意承受机制伤害；高配提前击败同样有效。

## 后期减负

同一副本、同一章节、同一难度真实手动通关一次后，可用正式资格快捷结算。仍需满足入场条件，沿用相同普通通关收益、装备序列、品质保底、材料和容量托管，不额外消耗丹药；不再重复首通奖。无资格不能扫荡，新难度要先亲自打通。

快捷结算可推进普通副本日常；“再铸新器”的手动试锋必须真正战斗。世界Boss和故事精英不能扫荡。Boss仍每天至多3次正式挑战、按当日最高单次有效伤害补差，不保证每次重复挑战都有新增奖励。

日常三选一和周主题仍先接后计，奖励材料；修为挂机与主动装备养成分别推进。材料生产、NPC交易与派遣仍按行动，不是离线自动刷物。

## 旧版进度与可靠恢复

旧长线内容升级先独立备份，再一次性事务升级；保留已获境界和当前阶段完成比例。旧自由历练不转换，schema1仍须显式迁移。升级前遗留的旧版数据现在须由运维按README先迁入待认领区，再认领给账号，具体步骤与规则以README和R4_API为准。

进度由服务端自动同步，刷新、停服重启或换设备登录后恢复完整进度；原先的手动存取与位置回退功能已随多用户化退役，因此不能再用它重领故事奖励、返还资格或重复迁移。所有关键结算在后端事务中处理，提交成功才会提示“进度已同步”；提示保存失败或结果未知时，应重试原操作而不是另发新操作。
