# 归墟修行手札 GDD v1.0（PM 授权冻结）

## 1. 范围与体验
单人、本地、中文文字修仙，HTML/CSS/JavaScript + Python。行动回合制，无真实时间、概率、离线收益、寿命、永久死亡或外部账号。目标：由炼气一层修至筑基，战胜归墟之影，得到明确结局。姓名去首尾空白后最多 12 字符，未填写或为空白时由服务端使用“归墟客”，不选择出身。

首版包括三处区域、修炼/突破、采药/炼丹、功法升级、确定性战斗、可选交易、引导目标、日志、自动与单槽手动存档及重开。本文数值为完整规则输入；架构可调整字段命名但不得改变语义，接口文档为最终机器字段契约。

### 系统最终取舍
| 系统 | 首版决定 |
| --- | --- |
| 修炼、境界、探索、战斗、丹药、功法、交易 | 按本文固定规则实现 |
| 背包 | 仅灵石账目、药草和回春丹数量，无物品网格、重量、装备 |
| 宗门、奇遇 | 后续扩展；首版宗门仅可作为剧情背景，不做加入、声望、经营或随机奇遇系统 |
| 任务 | 派生当前主线目标，胜利自动标记，无独立任务树或手动领奖 |
| 装备、随机词缀、天赋出身、多角色、多人、挂机 | 不做，后续另行立项 |

## 2. 权威状态与初值
| 字段语义 | 初值与约束 |
| --- | --- |
| name | 玩家姓名 |
| realm | 0；0/1/2/3 对应炼气一层/二层/三层/筑基 |
| cultivation | 0；整数，不小于 0，首版上限 9999 |
| hp/mp | 60/12；不小于 0，不超过对应上限 |
| stones/herbs/pills | 灵石 0/药草 0/回春丹 0；整数 0–9999 |
| technique | 功法《归元诀》等级 0；范围 0–2 |
| region | village；初始青岚村 |
| victories | 空集合；enemy_id 首次胜利标记 |
| battle | null；战斗中含敌人 ID、当前气血、已结算敌方回合数 |
| completed | false；最终胜利后永久 true，直到新局 |
| actions_taken | 0；每次成功玩法动作 +1，查看/失败请求不计 |
| logs | 只保留最近 100 条已提交事件，含行动编号和中文结果 |

schema_version、全局单调 revision、请求去重等为架构元信息。派生属性不接受客户端修改：

| realm | 气血上限 | 灵力上限 | 基础攻击 | 下一次突破消耗修为 |
| --- | --- | --- | --- | --- |
| 0 | 60 | 12 | 8 | 32 |
| 1 | 80 | 16 | 11 | 64 |
| 2 | 100 | 20 | 14 | 96 |
| 3 | 140 | 28 | 19 | 无 |

实际攻击 = 基础攻击 + technique × 2。资源到达上限时截断新增收益；若某行动的全部收益均已满，则拒绝且不推进。生命/灵力恢复独立截断。

## 3. 区域、成长与解锁
| region ID | 名称 | 解锁 | 探索一次所得 | 敌人 |
| --- | --- | --- | --- | --- |
| village | 青岚村 | 初始 | 灵石 +3，药草 +1 | 山狼，可选练手 |
| forest | 灵雾林 | realm ≥1 | 灵石 +6，药草 +2 | 雾林妖猿，突破所需 |
| ruins | 归墟古境 | realm ≥2 | 灵石 +9，药草 +3 | 守阵石傀；realm=3 可挑战归墟之影 |

突破 0→1 只需修为；1→2 另需战胜妖猿；2→3 另需战胜石傀。消耗表中修为后境界 +1，气血/灵力恢复新上限，已有修为余量保留。突破保证成功，不花材料。筑基后不可再突破。区域解锁只增不减，切换已解锁区域免费、不计动作；不可在战斗中切换。

## 4. 非战斗动作
以下动作均要求 battle=null。除探索/挑战外，在任一已解锁区域都可执行。

| 动作 ID | 条件/成本 | 效果 |
| --- | --- | --- |
| cultivate | 修为未满 | 修为 +(6+2×realm)，即6/8/10/12，免费 |
| rest | hp 或 mp 未满 | 气血 +30、灵力 +8，免费 |
| gather | 药草未满 | 药草 +2，免费 |
| alchemy | 药草 ≥3，丹药未满 | 药草 −3、回春丹 +1 |
| explore | 当前区域已解锁 | 获得区域表收益，无随机战斗 |
| upgrade | technique<2；0→1 花12灵石，1→2 花24灵石 | 扣灵石，功法等级 +1；不回血回蓝 |
| buy_pill | 灵石 ≥8，丹药未满 | 灵石 −8、回春丹 +1 |
| sell_herbs | 药草 ≥2，灵石未满 | 药草 −2、灵石 +3 |
| breakthrough | 满足境界表与首胜条件 | 按第3节执行 |
| challenge | 目标属于当前区域且已解锁 | 开始指定战斗，敌人满血，敌方回合计数0；本动作敌人不攻击 |

动作参数契约：`travel` 只接受 `{"region":"区域ID"}`；`challenge` 只接受 `{"enemy":"敌人ID"}`；其余玩法动作 params={}，拒绝额外参数。travel 不得选择未解锁区域，战斗中不可用；选择当前区域时拒绝为无变化动作。save/load 使用独立端点，不作为玩法动作。

交易为可选便利，无每日数量和强制任务。所有敌人可重复挑战；重复胜利仍发固定资源奖励，但首胜标记不重复产生。胜利自动写标记，不另设任务领奖按钮。挑战归墟之影还需 realm=3 且未通关；通关后禁再次挑战最终敌人，其余成长活动保留。

## 5. 敌人和战斗顺序
| enemy_id | 名称 | 气血 | 常规攻击 | 重击 | 胜利灵石/修为 |
| --- | --- | --- | --- | --- | --- |
| wolf | 山狼 | 36 | 8 | 14 | 6 / 4 |
| ape | 雾林妖猿 | 80 | 12 | 20 | 12 / 0 |
| sentinel | 守阵石傀 | 140 | 16 | 28 | 18 / 0 |
| shadow | 归墟之影 | 220 | 22 | 38 | 30 / 0 |

每个敌人的三回合循环相同：常规攻击 → 蓄势（不造成伤害）→ 重击，再重复。由“已结算敌方回合数 % 3”确定下一意图，挑战后第一意图为常规攻击。界面预告具体动作与伤害；无敌方恢复、护甲、命中或暴击。

战斗动作要求 battle!=null，除撤退外均在玩家效果后执行敌方本回合：

| 动作 ID | 成本与玩家效果 |
| --- | --- |
| attack | 免费，对敌造成实际攻击伤害 |
| power_attack | 灵力 −6，对敌造成实际攻击 ×2 伤害 |
| defend | 灵力 +3（截断至上限）；本回合敌人伤害变为向下取整的50% |
| use_pill | 丹药 −1，气血 +45、灵力 +6；hp/mp 均满时拒绝 |
| flee | 无敌方反击，battle=null，无奖励、不扣其他资源 |

结算顺序固定：校验全部条件 → 扣费并应用玩家效果 → 敌血≤0则胜利，发奖励/首胜标记，清战斗，本回合无反击 → 否则敌方按预告结算并递增敌方回合数 → hp≤0则败退，清战斗，回青岚村且 hp=1，保留灵力、已获资源和成长。敌血最小为0；没有相互同归于尽。败退不发本战奖励。敌人战斗内血量不保留到下一次挑战。

## 6. 目标、结局与防卡死
当前目标依序派生：修为达32并突破 → 妖猿首胜且修为达64并突破 → 石傀首胜且修为达96并突破 → 战胜归墟之影 → “归墟已平，修行未止”。目标显示各条件实际完成度；可自行调整修炼和战斗先后。

最终胜利设 completed=true，显示结局：玩家稳固筑基，以归元之息平息古境，留在山中继续修行。可继续采集、修炼、交易及普通战斗，也可确认后新局。姓名和成长不自动清空。

hp=1、灵力/灵石/药草/丹药全为0仍可静养、修炼、采药，突破必需物品均不依赖有限掉落。不得因死亡、时间或穷困锁死；战斗中资源不足可防御回蓝或撤退。无效行动保持整个状态（含日志和行动计数）不变。

## 7. 存档与交互最低要求
每次成功玩法动作原子自动保存，战斗进行中也保存敌血与回合；刷新与重启继续当前战斗。显示已保存版本。另提供一个手动快照槽位（slot），不提供多档管理：

- save：将当前完整游戏状态（包括战斗、行动计数和日志）存入槽位；有槽位时界面说明将覆盖。保存槽位不改变游戏状态和行动计数，但成功时 revision +1。
- load：有槽位时才可用；确认将覆盖当前进度后恢复该快照的完整游戏状态，可以恢复到过去的行动计数和日志。操作不计游戏行动，但成功时 revision +1；不把 revision、schema_version 或请求去重记录回退到快照值。保留槽位，可再次读取。
- 新局：明确确认后建立初始游戏状态，并清空手动槽位；全局 revision 继续递增且保留请求去重历史。旧标签页因版本过期被拒绝，不得污染新局。
- save/load 与玩法写操作使用相同版本检查、去重和原子事务；空槽读取、损坏数据或写入失败不得更改当前状态。不把手动槽位当作数据库损坏恢复机制；架构负责独立一致性备份/恢复命令，损坏存档不静默重建。

所有动作展示消耗/收益及禁用原因，战斗展示下一意图与确定伤害。提交中禁用写操作，失败和过期版本显示可恢复提示。前端只渲染后端权威结果，不推演到账资源。成功切换区域也必须持久化并推进 revision，但不增加 actions_taken；其他成功玩法动作均计一次。

## 8. 验收与数值基线
推荐公开路线不要求功法或补给，能证明零资源不会卡死。以下每场均由突破回满状态开始，“强/守/普”分别是强攻/防御/普攻：

| 阶段 | 修炼与突破 | 战斗动作顺序 | 胜后气血/灵力 |
| --- | --- | --- | --- |
| 炼气一层→二层 | 修炼6次获得36修为；突破剩4 | 前往灵雾林，挑战妖猿：强、强、守、强、普、普 | 46 / 1 |
| 炼气二层→三层 | 再修炼8次，修为68；突破剩4 | 前往归墟古境，挑战石傀：强、强、守、强、普、守、强、普 | 24 / 2 |
| 炼气三层→筑基 | 再修炼10次，修为104；突破剩8 | 同区挑战归墟之影：强、强、守、强、强、守、强、普、普 | 36 / 4 |

合计53次成功玩法动作：24修炼 +3突破 +3挑战 +23战斗指令，不计创建、切区、保存和读档。强攻耗6灵力，无法只连续强攻完成必需战斗；在重击回合防御既减伤又回蓝，普通攻击用于节省灵力及收尾。

可在主线前后体验可选闭环：初始采药2次、炼丹1次，得到1丹及1药草；任意战斗受伤后使用丹药将耗一回合并可能改变后续指令，不能直接沿用上表统计。妖猿首胜12灵石可直接购买功法一级；石傀首胜18灵石加古境探索一次9灵石，可付24升至二级。默认路线证明不升级也可通关，升级提高每次攻击2点而非强制门槛。具体可选路径由自动化和试玩另行验证，不虚报最优路线。

首轮阅读游玩约10–20分钟只是设计目标，未实测；不人为凑70次操作或设置点击延迟。QA 需独立验证上述53动作路线及全部动作条件、属性上限、两次功法升级、可选交易、败退/撤退、零资源恢复、首胜及奖励、防重复提交、战斗中自动续存、手动save/load、元数据不回退、新局清槽、损坏拒绝及终局继续。上表为人工算术基线，尚未实际运行验证。
